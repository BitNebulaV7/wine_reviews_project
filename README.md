# Wine Reviews Project

Exploratory data analysis with Pandas on the Kaggle Wine Reviews dataset.

## Structure

- `data/raw/` : raw dataset (kept out of repo)
- `data/processed/` : processed/cleaned data
- `notebooks/` : exploratory notebooks
- `scripts/` : utility scripts (data checks, cleaning)

## How to run

1. Put raw CSV in `data/raw/` (or run provided download script).
2. Create virtualenv and install requirements:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```
